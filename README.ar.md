## لماذا

عملاء VPN كثيراً ما يعرضون **"تم الاتصال"**، لكنهم لا يخبرونك دائماً من أي دولة يخرج منها
بريطك **فعلياً**: تقسيم الأنفاق (Split Tunneling)، تسرب DNS، نفق متعطل، أو إعادة توجيه
"ذكية" — كل هذا قد يُبقي كله أو بعض بريطك في الدولة السابقة.

يجيب GeoFlagMenuBar عن السؤال الوحيد المهم: **ما الذي يراه الإنترنت الخارجي عنك الآن؟**
يتحقق من عنوان IP العام عبر عدة خدمات جغرافية مستقلة ويعرض الدولة كعلم في شريط القوائم —
مع تحديث فوري عند أي تغيير في الشبكة.

## المميزات

- 🏳️ **علم دولة حي** في شريط الحالة (مثلاً: 🇬🇧 → 🇩🇪 في لحظة تغيّر المسار)
- 📋 **انقر على العلم لعرض التفاصيل**: IP العام · الدولة (رمز ISO + العلم) · المدينة · وقت آخر فحص، مع وسم *«(تغيّر!)»* عند تغيّر نقطة الخروج
- ⚡ **استجابة فورية** — دون انتظار الدور):
  - حدث النظام `network_change`: تشغيل/إيقاف VPN، Wi-Fi ↔ Ethernet، توصيل كيبل، تبديل نقطة الاتصال
  - `NWPathMonitor`: عند انقطاع الشبكة تتحول الأيقونة فوراً إلى 🚫 — وتعود للعلم عند الرجوع
  - استيقاظ الجهاز، تغيّر الوقت/المنطقة الزمنية، فتح القائمة
- 🛰 **ثلاثة مصادر مستقلة**: `ipinfo.io` و`ifconfig.co` و`api.myip.com` — يفوز أول من يستجيب؛ مهلة 5 ثوانٍ؛ 🚫 إذا تعذّر الوصول للجميع
- 🪶 **خفيف جداً**: ملف Swift واحد، بدون أي اعتماديات خارجية، ~50 MB ذاكرة، ~0% معالج، بلا خدمة خلفية أو مثبّت
- 🔒 **خصوصية بالتصميم**: بلا تحليلات أو حسابات أو سجل — فقط طلبات HTTPS GET مجهولة إلى الخدمات الثلاث

## التثبيت

### الطريقة 1 — تنزيل نسخة جاهزة

1. نزّل `GeoFlagMenuBar.zip` من أحدث [**Release**](https://github.com/Uralmans/GeoFlagMenuBar/releases/latest) (~70 KB، ثنائي عالمي: Apple Silicon + Intel)
2. فك الضغط → انقل **GeoFlagMenuBar.app** إلى أي مكان (`/Applications` اختياري)
3. التشغيل الأول: **زر أيمن → فتح** (توقيع ad-hoc؛ تأكيد لمرة واحدة، ثم يفتح كالمعتاد)

*نصيحة: إذا وصل التطبيق عبر `git clone` أو AirDrop فعادةً لا يأخذ سمة الحجر الصحي ويُفتح بنقرة مزدوجة.*

### الطريقة 2 — البناء من المصدر (أمر واحد)

يحتاج macOS 13+ و[أدوات سطر الأوامر](https://developer.apple.com/download/all/) (`xcode-select --install`)؛ لا يلزم Xcode كامل:

```bash
git clone https://github.com/Uralmans/GeoFlagMenuBar.git
cd GeoFlagMenuBar
./build.sh
open build/GeoFlagMenuBar.app
```

ينتج البناء ثنائياً عالمياً موقّعاً (arm64 + x86_64) — انظر `build.sh`؛ إنه ~30 سطراً من zsh + `swiftc` فقط.

### التشغيل عند تسجيل الدخول (اختياري)

أضف التطبيق إلى *إعدادات النظام → عام → عناصر الدخول*، أو:

```bash
cp -R build/GeoFlagMenuBar.app /Applications/
osascript -e 'tell application "System Events" to make login item at end with properties {path:"/Applications/GeoFlagMenuBar.app", hidden:true}'
```

## كيف يعمل

```
┌──────────────┐  NWPathMonitor (فوري: صعود/نزول)      ┌───────────────────────┐
│ أحداث النظام │ ─────────────────────────────────────▶ │    منع الاهتزاز 1.5 ث  │
└──────────────┘  network_change / wake / clock         └───────────┬───────────┘
┌──────────────┐                                                     ▼
│ مسح كل 20 ث  │ ───────────────────────────────▶ 3×HTTPS GET (سباق، مهلة 5ث)
└──────────────┘                                          │ أول رد ISO-2 صالح
                                                          ▼
                                          علم إيموجي ← ISO-2 → الأيقونة والقائمة
```

- الطلبات تتسابق بالتوازي: يفوز أول جواب صالح (يخفي أي خلل في خدمة واحدة)
- كشف التغيير يقارن ثنائية (IP، الدولة) مع الفحص السابق؛ عند التغيّر: وسم في القائمة + تسجيل في سجل النظام
- عند انقطاع مسار الشبكة (NWPathMonitor) يتوقف جالف HTTP — لا مهلات بلا فائدة
- يعمل بأسلوب `LSUIElement`: بلا أيقونة في Dock، فقط أيقونة شريط الحالة

## حل المشكلات

| العَرَض | السبب / الحل |
|---|---|
| الأيقونة تعرض 🇺🇸 مع تفعيل VPN | عند الحفظ: kill-switch أو تقسيم الأنفاق في العميل يمرر جزءاً من البريطك مباشرةً — وهذا بالضبط ما يصطاده التطبيق. افحص IP في القائمة |
| 🚫 لكن الإنترنت يعمل | الخدمات الجغرافية الثلاث متاحة جميعها غير (جدار حماية، Pi-hole، خلل في DoH). القائمة → *Проверить сейчас* |
| تغيّر العلم ولم يتغير IP | قاعدة الأعراف الجغرافية حدّثت دولة عنوانك — حدث معتاد؛ العلم هو مصدر الحقيقة |
| التطبيق لا يبدأ بعد التنزيل | أعد **زر أيمن → فتح** مرة أخرى، أو: `xattr -dr com.apple.quarantine GeoFlagMenuBar.app` |
| سجلات للتصحيح | `log show --last 5m --predicate 'process == "GeoFlagMenuBar"'` |

## الخصوصية

- **بلا تتبع ولا كتابة**: لا يكتب التطبيق شيئاً إلى القرص (عدا الثنائي نفسه) ولا يحفظ أي سجل
- **البريطك الخارجي**: HTTPS GET إلى `ipinfo.io` و`ifconfig.co` و`api.myip.com` — ولا شيء غيرها
- **بلا أذونات**: لا يطلب الإشعارات أو المساعد أو القرص أو الزمرة
