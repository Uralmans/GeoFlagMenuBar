## Зачем

VPN-клиенты часто пишут **«Подключено»**, но не говорят, из какой страны трафик выходит
**на самом деле**: сплит-туннелирование, утечки DNS, «зависший» туннель или «умный»
«обходной» маршрут — всё это может оставить часть или весь трафик в предыдущей стране.

GeoFlagMenuBar отвечает на единственный важный вопрос: **что видит о вас внешний интернет
прямо сейчас?** Приложение проверяет ваш публичный IP через несколько независимых гео-сервисов
и показывает страну флагом в меню-баре — мгновенно обновляя его при смене сети.

## Возможности

- 🏳️ **Живой флаг страны** в статус-баре (например, 🇬🇧 → 🇩🇪 в момент смены маршрута)
- 📋 **Клик по флагу — детали**: публичный IP · страна (ISO + флаг) · город · время последней проверки, с пометкой *«(изменилось!)»* при смене точки выхода
- ⚡ **Мгновенная реакция** — без задержек на опрос:
  - системное событие `network_change`: включение/выключение VPN, Wi-Fi ↔ Ethernet, подключение кабеля, переключение хотспота
  - `NWPathMonitor`: в момент обрыва значок сразу становится 🚫 — и возвращается к флагу при появлении сети
  - пробуждение Mac, смена времени/часового пояса, открытие меню
- 🛰 **Три независимых источника**: `ipinfo.io`, `ifconfig.co`, `api.myip.com` — побеждает ответивший первым; таймаут 5 с; 🚫, если никто не доступен
- 🪶 **Легковесность**: один Swift-файл, ноль сторонних зависимостей, ~50 МБ RAM, ~0% CPU, без фоновых демонов и установщиков
- 🔒 **Приватность по конструкции**: без аналитики, аккаунтов и накопления истории — только анонимные HTTPS GET к трём гео-сервисам

## Что вы увидите

| Значок | Смысл |
|:---:|---|
| ⏳ | Идёт проверка (или сеть только что вернулась) |
| 🇬🇧 🇩🇪 🇷🇺 … | Текущая страна выхода |
| 🚫 | Нет сети / сервисы недоступны |

## Установка

### Вариант 1 — готовая сборка

1. Скачайте `GeoFlagMenuBar.zip` из последнего [**Release**](https://github.com/Uralmans/GeoFlagMenuBar/releases/latest) (~70 КБ, universal-бинар: Apple Silicon + Intel)
2. Распакуйте → перенесите **GeoFlagMenuBar.app** куда удобно (`/Applications` — по желанию)
3. Первый запуск: **правый клик → «Открыть»** (ad-hoc подпись; подтверждение одноразовое, дальше открывается как обычно)

*Совет: если приложение попало на Mac через `git clone` или AirDrop, карантинный атрибут обычно не ставится, и оно открывается двойным кликом.*

### Вариант 2 — сборка из исходников (одна команда)

Нужны macOS 13+ и [Command Line Tools](https://developer.apple.com/download/all/) (`xcode-select --install`); полный Xcode **не требуется**:

```bash
git clone https://github.com/Uralmans/GeoFlagMenuBar.git
cd GeoFlagMenuBar
./build.sh
open build/GeoFlagMenuBar.app
```

Сборка даёт подписанный universal-бинар (arm64 + x86_64) — см. `build.sh`, это ~30 строк обычного zsh + `swiftc`.

### Автозапуск при входе (по желанию)

Добавьте приложение в *Системные настройки → Основные → Объекты входа*, или:

```bash
cp -R build/GeoFlagMenuBar.app /Applications/
osascript -e 'tell application "System Events" to make login item at end with properties {path:"/Applications/GeoFlagMenuBar.app", hidden:true}'
```

## Как это работает

```
┌──────────────┐   NWPathMonitor (мгновенно up/down)    ┌───────────────────────┐
│ События macOS│ ─────────────────────────────────────▶ │    Анти-дребезг 1,5 с │
└──────────────┘  network_change / wake / clock         └───────────┬───────────┘
┌──────────────┐                                                     ▼
│ Опрос 20 сек │ ───────────────────────────────▶ 3×HTTPS GET (гонка, 5 с TO)
└──────────────┘                                          │ первый валидный ISO-2
                                                          ▼
                                        эмодзи-флаг ← ISO-2 → значок + меню
```

- Запросы идут параллельно «в гонке»: побеждает самый быстрый валидный ответ (сглаживает сбои любого одного сервиса)
- Детекция смены сравнивает пару `(ip, страна)` с прошлой проверкой; при изменении — пометка в меню + запись в unified log
- Пока сеть лежит (`NWPathMonitor`), HTTP-опрос приостановлен — ноль бесполезных таймаутов
- Запускается как `LSUIElement`: без иконки в Dock, только значок в статус-баре

## Решение проблем

| Симптом | Причина / что делать |
|---|---|
| Значок показывает 🇺🇸 при включённом VPN | kill-switch или сплит-туннелинг клиента пускает часть трафика напрямую — именно это приложение и ловит. Проверьте IP в меню |
| 🚫, но интернет работает | Все 3 гео-сервиса недоступны (фаервол, Pi-hole, проблема с DoH). Меню → *Проверить сейчас* |
| Флаг сменился, а IP нет | Гео-база обновила страну вашего IP — бывает; флаг — источник истины |
| Приложение не стартует после скачивания | Повторите **правый клик → Открыть**, или: `xattr -dr com.apple.quarantine GeoFlagMenuBar.app` |
| Логи для отладки | `log show --last 5m --predicate 'process == "GeoFlagMenuBar"'` |

## Приватность

- **Без трекинга и записи**: приложение не пишет ничего на диск (кроме самого бинарника) и не хранит историю
- **Исходящий трафик**: HTTPS GET к `ipinfo.io`, `ifconfig.co`, `api.myip.com` — и всё
- **Без разрешений**: не просит нотификации, ассистента, доступ к диску или ключнице
